PAGES
- index.html    Home: hero, quick facts, links to other pages, figure + figcaption
- trails.html   Trails: comparison table and route articles
- events.html   Events: dated event list, audio element with controls and caption
- contact.html  Contact: form (label, text, email, select, textarea, button)
- thanks.html   Thank-you page the contact form sends visitors to

FILES
- css/style.css            The one external stylesheet (hand-written, no frameworks)
- images/                  All images, each with meaningful alt text
- media/park-ambience.wav  Park sound clip used on the Events page

HOW THE REQUIREMENTS ARE MET
- CSS variables for colors and fonts live at the top of css/style.css.
- Flexbox: header, nav, buttons, form fields, footer, event list.
- Grid: hero, quick facts, card rows, trail and event layouts, contact layout.
- Breakpoints: phone (default), tablet (640px), desktop (1000px).
- Hover and focus states: links, nav, buttons, form fields.
- Name and email fields use the required attribute.

NOTES
- Images and the audio clip were generated for this project, so all media is original.
- To run: open the folder in Visual Studio and open index.html in a browser
  (Live Server works too).
